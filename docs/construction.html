How the Projection Is Built

What this tool does, in the order it does it: the inputs it takes, the three runs it makes of them, the two artefacts it derives, and the one number the whole construction exists to measure. The debate records why each decision was taken; this page records what was built.

Purpose

An operator files a pfd mask and a set of operating parameters. An administration then examines the system against the Article 22 epfd limits by reading those declarations — not the system. So the declarations decide the verdict, and a declaration looser than the system it describes costs the operator real transmit power for nothing.

This tool measures that cost. It simulates the operated system, derives the declarations from the simulation rather than asserting them, and runs the examination twice: once against the system as it behaves, once against the system as it is declared. The distance between those two answers is the price of the declaration.

What the numbers are about

Every STEAM-2 figure in this repository is a figure about the payload this project assumed for it — scene-default pattern and layout, an assumed peak gain, power set to meet the filed cap at boresight. The operator’s filed STEAM-2B mask, examined the administration’s way, sits 7–16 dB below that assumed system’s truth at every latitude (record). The construction is indifferent to which system is in the profile; the conclusions about STEAM-2 are not.

The three quantities, once

T — the truth: epfd from the live beam composition of the operated system. E1 — the examination reading the derived mask and the derived R set. E1 − T — the projection margin: what the declaration gives away, and at the same dB-for-dB rate, the operating power the system could have been licensed for.

The profile is the system. There are no stand-in fields: if a quantity shapes what the satellites do, it is declared there and nowhere else.

Means: three runs, in this order

The three runs are separate on purpose. The probe is saturated — demand at the declared cap, activity, illumination duty and operating fraction at 1 — because a declaration is an envelope of what the system MAY do, and a value measured under a traffic sample is a promise the operator never made. The truth sweep carries the real traffic. And the probe must not be the run that verifies it: a declaration measured on a run envelopes that run trivially, which would make the acceptance test vacuous.

Two life cycles of a pfd mask: derived, or given

The same file format enters the construction in two ways, and the rules differ at every station. A derived mask is a product: the saturated probe measures it, alongside the R set, from the system the profile describes. A given mask is an input: a filed declaration taken verbatim, with nothing known about the payload behind it. The operator’s rulings draw the line in one sentence — a declared mask cannot move; a derived mask moves inside the loop — and the figure shows where each may change.

The line the rulings draw

A declared mask cannot move: it is a filed commitment, and the gates an R set declares act on boresights that the mask’s per-direction maximum no longer remembers, so no gate can be carved into it after the fact. The one adaptation geometry alone warrants is the dark row — a sub-satellite latitude from which no servable cell exists radiates nothing, and the whole row goes to the null. A derived mask moves, because it is re-derived: adaptation done right is a new measurement of the payload under the commitments, never surgery on the artefact. In both lanes the mask is examined the same way; only in the derived lane can the result be tested against a truth.

Process: two loops, and what each may move

The optimization loop

The two loops above say what may move. This is the iteration itself — what one pass does, what changes before the next one, and what stops it.

The objective is stated once and does not change: minimise E1, subject to E1 ≥ T, with T held fixed. T is the system; it is not the thing being optimised. Every dB taken off E1 − T is a dB of transmit power the operator may be licensed for and currently is not.

The beam capacity, in three regimes

Whether declaring the capacity costs anything depends on which side of two numbers it sits: Ksat, the most same-colour beams the saturated probe ever lights (20 on STEAM-2), and Ktruth, the most today’s traffic ever lights (11). The line between the rows is not whether T moves but whether the knob changes what the system does: a commitment is declaration-side if and only if today’s granted links are unchanged under it. Rows one and two leave the links identical, so they are declarations — the second an honest one, a promise about a peak the system may never sell. Row three changes today’s links, so it is a redesign, to be chosen or refused as engineering. The non-monotone T is the proof the line matters: a knob that can worsen compliance cannot be a declaration-tightening move, because declarations never change behaviour.

The middle row is the one an operator would want: a commitment the system already honours at today’s traffic, that buys 0.8–3.3 dB on the examination, and whose only price falls on the busiest hour. The bottom row maps the extreme. Its lesson is not the dB: it is that a binding cap moves T in both directions. A refused link is not dropped, it is reassigned to the next-best satellite, and at some victims that satellite sits in worse geometry — T improved 1.5 dB at the equator and worsened 0.9 dB at latitude 50 from the same declaration. A tighter payload commitment is not monotone for compliance.

A control that did not hold, then measured

In the bottom row the derived R set also changed: the saturated probe could not place 47% of peak demand, and min_exclude tightened to 26.5° and 33.0° at the 35° and 45° bands against 22.0° everywhere on the record. The examination reads that exclusion, so the E1 gain could not be attributed to the envelope alone — until an examination-only run held the record’s R set fixed and swapped in the cap-4 mask. The result differs from the cap-4 record at one latitude by 0.1 dB and at the other six not at all: the exclusion’s share is nil, and the whole E1 gain — 3.5 to 6.4 dB by latitude — is the top-4 envelope’s. Why the tightened exclusion did not register has since been measured, and the first explanation offered for it — a notch in the derived mask — was wrong. With min_exclude forced to 0° against the record mask — no exclusion zone at all — E1 moved at none of the seven latitudes, max epfd by +0.1 dB at one. The dissection of that mask shows why, and it is not a notch: power within 3 dB of the peak reaches alpha 12–16° against the declared 22°, the main-lobe edge of beams gated at their boresight reaching the neighbouring ground at this cell size. The mechanism is the algorithm’s own: Step 22 counts main-beam satellites regardless of the zone, and when the zone is lifted the same satellites, being the strongest, are the first the capped pick takes. In-zone satellites near the victim’s boresight are summed either way; the rest are too weak to register. The filed two-level mask measures inert for the complementary reason — its in-zone values sit 30 dB down — so the result holds for both mask shapes met so far, and the consistency check now reports each mask’s own reach into the declared zone rather than assuming one.

Where this leaves the inner loop today

For a payload that declares nothing beyond its reuse plan, the inner loop is spent: the service span certifies nothing on a global system, the grid is converged at 0.1 dB, and the beam count has no warrant. Declaring the co-frequency beam capacity — a real property of the hardware — is what turns the beam count into a lever, and on STEAM-2 it recovers 0.0–1.8 dB at the readout’s own K with T untouched. What remains — 6.4 to 10.9 dB in band at 0.1 d — is the envelope price proper: the cost of describing a whole operating space with a single conservative surface. At 1.0 d, its convergence pair, the gap reads 7.5 to 10.7 dB in band (11.0 at latitude 60), and the run settled what moves with depth: the derivation does not — the R set and the mask derived at 1.0 d are identical to the record’s, so E1’s movement was the examination sampling a fixed declaration — while the truth does, by up to 5.4 dB at single latitudes, flattening to −9.3…−10.9 across all seven. Its pair, a truth-only rerun at 0.5 d, moved no figure by more than 0.5 dB at latitudes 0, 10, 20, 30 and 60, so the gap is firm at 7.5 to 8.8 dB in band there and T at −9.3 to −10.9; at 40 and 50 the truth moved 2.8 and 2.6 dB between the two depths, so those two latitudes, and the widest gap of 10.7 at 50, stay provisional until a 2.0 d truth sweep pairs them. Differences measured at fixed depth stand. A cap below what today’s traffic reaches recovers more and moves T — in both directions, since refused links are reassigned rather than dropped — which makes it a design decision about the system rather than a better description of it.

The rules the construction obeys

Each of these was bought with a measurement, and each is stated so it can be checked rather than believed.

  • Measurement, not assertion. Every declared value is measured on the probe. A mask that asserts can assert what the scheduler does not enforce.
  • Saturate before measuring. Traffic may only thin what is lit, so a declaration measured under traffic is smaller than the commitment it stands for.
  • Unvisited is not unreachable. Nothing is declared absent because a finite probe happened not to visit it. A null needs a closed-form certificate from declared commitments.
  • The read-rule law. A declared array is safe if and only if its read-rule reconstruction bounds the measurement everywhere — not if its rows are correct at their own coordinates. See below. Header attribute and per-latitude array are mutually exclusive per quantity, and the nearest-row read is total: the outermost row governs every latitude beyond the table, so a set of rows is complete everywhere and a set carrying both forms of a quantity is an invalid filing — reported, not read under an invented precedence (design brief 3.8, EPS V43 6.7.2.2). An out-of-span fallback in the examination’s resolver read the first derived sets as no floor and no cap at latitudes 50 and 60 until it was removed.
  • Figures travel with their controls. A margin carries the depth it was resolved at and the grid it was worst over. A comparison names what was held fixed. An absolute figure is quotable only with a convergence pair: the same statistic at depth d and at least 2d, moving no more than a stated tolerance — 0.5 dB by default, 0.1 dB the bin floor — with both depths and the tolerance named where the figure is quoted. Differences at matched depth remain quotable as differences. The percentile floor guards a percentile’s existence; the pair guards a value’s stability, which is a property of the artefact — a two-level mask settles at once, a side-lobe-structured one needs samples.
  • Adequacy is the derivation’s test, not the system’s. If E1 falls below T, the declaration failed to envelope the system. That is a granularity failure of the measurement, never a compliance failure of the system.
  • Every grid is one of three things, and is named as such when introduced. A declaration — then its read-rule reconstruction must bound the measurement. A measurement — then its extrema travel with the grid. A prescription — then reproducing it exactly is the requirement, as the examination’s own worst-case geometry search is. Five defects of one family were found in a day; asking this question at the moment each grid was introduced would have caught every one before it ran.

The read-rule law, drawn

Implementation status

The nearest-read case is implemented as stated: both mask samplers envelope the band a row governs. The interpolated case is implemented conservatively: the deriver applies a per-row sliding minimum, which satisfies the hull condition without exploiting it — the declaration it produces is safe and under-claims the exclusion the operator could have declared. The difference is exactly zero on both live cases, where MIN_EXCLUDE is flat; it will matter when a case flies a genuinely varying alpha table, and the refinement is parked until one does. The rule above is the rule; this line records how far the code has caught up with it.

What a run emits

Profile, R set (Part B XML and the designer’s JSON) and pfd mask are written into one directory per run, so the three artefacts describe one system and can be read back together. The record beside them carries the verdict table, the derived declaration, the per-latitude E1 − T gap and the adequacy statement.
