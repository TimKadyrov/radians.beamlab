How the Projection Is Built

How the tool builds the declarations a filing carries, and how it measures what they cost. The measure is one number per latitude: the gap between the examination of the declarations and the epfd the simulated system really produces.

What the projection is

A non-GSO filing carries two declarations. The pfd mask gives, for each sub-satellite latitude, the strongest power flux-density a satellite may produce in each direction. The R set is the operating-parameter set of Rec. ITU-R S.1503-4 Part B; its fields include the exclusion angle, the elevation floor, the co-frequency caps, the minimum angles and the served latitudes.

The Bureau’s examination under S.1503-4 judges the system against the Article 22 limits on equivalent power flux-density (epfd) by reading those declarations, not the system. So the declarations decide the verdict.

A declaration looser than the system costs transmit power. epfd moves dB for dB with the per-beam power, so every dB the declaration adds is a dB of power the system could have been licensed for.

The tool measures that cost. It simulates the system, derives the declarations from the simulation instead of writing them by hand, and computes epfd twice at the same victim earth stations: once from the simulated system, once as the examination reads the declarations.

Tech · the three quantities

T, the truth: the epfd of the simulated system. Every satellite visible from the victim counts, at the level its live beams put there, power-summed; the examination’s selection rules are not applied.

E1: the epfd the examination computes from the declared pfd mask and the declared R set, under the selection rules of S.1503-4 §D5.1.4.1.

E1 − T, the gap or projection margin: what the declaration gives away, and at the same dB-for-dB rate the operating power the system could have been licensed for. It is read as the T point margin minus the E1 point margin, in dB. A correct declaration covers the system, so E1 is never below T.

The profile is the system. There are no stand-in fields: a quantity that shapes what the satellites do is declared in the profile and nowhere else.

The three runs

The Compliance loop window’s Run loop and the console loop mode make three runs of the same system, in this order.

  • 1. The derivation probe measures the R set. It is saturated: no victim, no limit, demand raised to the declared co-frequency cap when one is declared, and activity, illumination duty and operating fraction at 1. It runs at the loop’s own depth, step and latitude band. Declared minima floor the observed minima, to 0.1°; declared maxima carry the observed maxima; a quantity never observed stays undeclared.
  • 2. The truth sweep runs the profile as it stands, with its real traffic, and places a victim at each latitude of the grid. It gives T.
  • 3. The examination sweep reads the pfd mask and the R set at the same victims, on the same step and duration, as S.1503-4 does. It gives E1.

The pfd mask is not measured on the probe. It is the profile’s declared mask when the profile names one. Otherwise the loop computes it from the payload’s reachable envelope: in each direction, the strongest level any permitted beam position could produce, whether the orbit visits it or not, so the mask is conservative by construction. A later run reuses the computed mask while it is newer than the profile.

Naming an R set in Declared R set skips the probe and uses that set. The console loop mode’s reuse= argument reuses an earlier run’s R set and mask.

Tech · why the probe is separate and saturated

A declaration is an envelope of what the system may do. A value measured under a traffic sample is a promise the operator never made: traffic can only thin what is lit, so it gives a declaration smaller than the commitment. The probe must also not be the run that is later checked. A declaration measured on a run envelopes that run trivially, which would make the acceptance test E1 ≥ T empty.

Tech · the computed mask

The mask is computed on the loop’s latitude step and a 1° az/el grid. For fixed body-stabilised beams the reachable set at a latitude is the beam layout at the ascending and the descending pass headings. Each row is sampled at its band’s centre and both edges, and the mask takes the maximum over all of them. With a declared co-frequency beam capacity K, each cell sums only the K strongest same-colour contributions (the top-K envelope).

The service-span certificate writes as no transmission (the −1000 null of S.1503-4 §C1) every row from which no cell within the declared service latitudes can be reached, at the smallest declared elevation floor. It is computed in closed form from the declared commitments. A row governs the half-step either side of it, so a row goes dark only when no latitude in its band can reach the span.

Derived or given: two kinds of pfd mask

The same mask format enters the construction in two ways, and the rules differ.

  • A derived mask is a product: computed from the system the profile describes, beside the R set the probe measures.
  • A given mask is an input: a filed declaration taken as it is, with nothing known about the payload behind it.

A given mask cannot move. A derived mask moves inside the loop.

Tech · why a given mask cannot be reshaped

A pfd mask keeps only the strongest level in each direction and has lost which beam produced it. The gates an R set declares act on beam boresights, so no gate can be carved into the mask after the fact. The one change geometry alone warrants is the dark row: a sub-satellite latitude from which no servable cell exists radiates nothing, and the whole row goes to the null. The loop does not apply even that to a given mask; it examines the mask as it is.

A derived mask moves because it is computed again: adapting it means measuring the payload again under the commitments, never editing the file. Both kinds are examined the same way; only a derived mask can be tested against a truth. Inside the Compliance Loop describes the consistency check’s grades.

What a run writes

  • The profile, the R set (S.1503-4 Part B XML and the designer’s JSON) and, when the run computes it, the pfd mask go into one directory per run. The three describe one system and can be read back together; the R-set designer’s Derive & fill reads that directory.
  • A computed mask’s file name carries its latitude step, az/el step, service latitudes and the id of the code that produced it, so a rebuild of that code exports the mask again.
  • The console loop mode also writes a dated report: the verdict table, the declaration, the per-latitude gap and the acceptance statement.
  • The window shows T, E1 and the gap per latitude; Export table… writes the rows as CSV, headed by the run, its inputs, grid, depth, step and limit.

How a run is judged

Each latitude of the grid is one victim: an earth station at that latitude and the ES longitude, its S.1428 dish pointed at a GSO satellite at the GSO offset. Each run builds the epfd distribution at every victim over its duration and judges it against the limit.

  • The verdict. A latitude passes only if its distribution meets the limit at every tabulated point and nowhere crosses the limit curve drawn between the points.
  • The margins, in dB, positive when there is room to spare. The point margin is the limit epfd minus the measured epfd at each point’s percentage, the minimum over the points. The curve margin is the dB shift of the whole distribution that just clears the curve. The rule margin is the smaller of the two.
  • The deciding point is the limit point at the worst point margin. “max” is the maximum sample, read against the 0% row; it can only rise as the run lengthens. A percentage names a resolved percentile, which can move either way. On a tie the shortest time is named: a limit point below the floor reads the maximum’s bin, so where it ties with the 0% row the maximum is what decides (records made before 25 September 2026 named 0.029% there).
  • The depth is the number of steps per latitude. It sets the resolvable floor, 100% divided by the steps: a limit point below the floor is located, not decided.
  • The acceptance test. E1 must sit at or above T at every latitude: the E1 point margin never above the T point margin. When it holds, the loop reports ADEQUATE with the widest gap. When it fails, it names the latitudes where E1 sits below T.
Tech · the limit-curve rule

The rule is compliance against the Article 22 limit curve, adopted for this dataset. At every tabulated point the level exceeded for the allowed percentage of time must not pass the limit level (S.1503-4 §D7.1.3, over the §D7.1.2 CDF bins of 0.1 dB). Between the lowest and highest tabulated epfd the distribution must nowhere cross the limit curve, the log-linear interpolation of percentage between adjacent points, read with a tolerance of half a bin (0.05 dB) towards lower epfd. The gaps between tabulated points reach 5.4 to 34 dB in Table 22-1C, so a point margin does not bound a crossing: a distribution can clear both ends of a gap yet bulge above the curve inside it, and the examination under S.1503-4 fails such a case. The point-wise test alone is the lenient reading.

One iteration then ends in one of three ways.

E1 below T at any latitude is not good news. The declaration does not cover the system it describes, because the derivation was too coarse. The fix is to measure more finely, never to redesign the system.

Two loops, and what each may move

  • The outer loop designs the system. It may move the exclusion angle, the co-frequency cap (Nco, the most co-frequency links per cell), the power and the beam capacity, and T moves with them. It answers whether the system is compliant at all. The window’s advisors work here.
  • The inner loop describes the system the outer loop fixed. It may move only how the system is measured and stated, so T is fixed and only E1 comes down. It answers what the declaration costs.

The inner loop has one objective: minimise E1, subject to E1 ≥ T, with T held fixed. T is the system; it is not the thing being optimised. Every dB taken off E1 − T is a dB of transmit power the system may be licensed for and currently is not.

The console loop mode runs one pass of this search with its minimise argument, the granularity walk. It derives the declaration again at three granularities, coarse (mask az/el 2°), baseline (az/el 1°) and fine (half the latitude band and half the mask latitude step, az/el 1°), and examines each against the same truth. It rejects any candidate whose E1 falls below T and reports the best of the rest. The walk runs only when the declaration is derived, not reused.

What was measured

The findings below are on the STEAM-2 test system unless stated: 1 600 satellites at 1 150 km and 53°, minimum elevation 40°, exclusion angle 22°, Nco 4, Random selection. The victims sit at 0 to 60° N every 10°, at longitude 0, with the GSO satellite 10° east and a 1.00 m dish, judged against the Table 22-1B row for 17.8–18.6 GHz. Every run ran on a 60 s step unless a finding says otherwise, and examined the STEAM-2 declaration derived at 0.1 d. Each finding names its depth. The time-step finding says how far a 60 s figure can be trusted.

The STEAM-2 figures describe an assumed payload

Every STEAM-2 figure on this page is about the payload the tool assumed for STEAM-2, not the filed system. The pattern and beam layout are the scene defaults, the peak gain is assumed (35 dBi), and the per-beam power is set so that the boresight pfd meets the filed cap.

The operator’s filed STEAM-2B mask, examined as S.1503-4 specifies, sits 7 to 16 dB below this assumed system’s truth at every latitude (0.1 d, examined under the tool’s derived R set, not the filed one). The construction does not depend on which system is in the profile; the conclusions about STEAM-2 do.

The gap is the mask envelope’s

On STEAM-2 the whole gap comes from the mask envelope. The examination’s selection rules add nothing at the point that decides the verdict.

The decomposition runs three curves on one victim grid and one 60 s sample grid:

  • T: every visible satellite at its live value, no selection;
  • Esel: the examination’s selection rules (S.1503-4 §D5.1.4.1: the elevation gate, the exclusion zone, the MAX_CO_FREQ pick by highest contribution, MIN_ANGLE_AT_ES pruning, the main-beam always-include) applied to those same live values;
  • E1: the same selection over the declared mask.

Esel − T is what the selection rules do to the count; E1 − Esel is what the mask envelope adds. At the deciding point, by latitude from 0 to 60° N, in dB:

  • The zero is checked, not assumed: with no gate declared, Esel equals T bin for bin.
  • The 1.0 d run is the 0.5 d run extended on the same sample grid. Between them T moved 2.8 dB at 40° N and 2.6 at 50° N at the deciding point, and the selection component stayed 0.0 at every latitude. Differences at matched depth are the quotable quantity; the absolute levels carry their depth.
  • The three curves share the victim, so the decomposition has no term for the victim’s geometry. That component is measured separately, below.

So the price of the format on this system is the mask envelope’s, not the selection rules’, and the granularity levers act on exactly that component.

The beam capacity has three regimes

Declaring the co-frequency beam capacity costs nothing today as long as it is at least what today’s traffic lights. Below that it changes the system, and T moves in both directions.

The capacity K is the most beams of one frequency colour a satellite can light. The scheduler refuses a further same-colour link beyond it, and the computed mask sums only the K strongest same-colour contributions at each cell. Two numbers decide what declaring it costs, and both are measured:

  • Ksat, the most same-colour beams the saturated probe ever lights: 20 on STEAM-2;
  • Ktruth, the most today’s traffic ever lights: 11.

The line between the rows is not whether T moves but whether the capacity changes what the system does. A commitment is declaration-side if and only if today’s granted links are unchanged under it.

  • 20 and 12 leave today’s links identical, so they are declarations. The capacity of 12 is a promise about a peak the system may never sell.
  • 4 changes today’s links, so it is a redesign, to be chosen or refused as engineering. Its T moves both ways, and that is the proof the line matters: a change that can worsen compliance cannot be a declaration-tightening move, because declarations never change behaviour.

The capacity of 12 is the one an operator would want: a commitment the system already honours at today’s traffic, that buys 0.8 to 3.3 dB on the examination by latitude, and whose only price falls on peak demand.

The capacity of 4 moves T in both directions. A refused link is not dropped: it is reassigned to the next-best satellite, and at some victims that satellite sits in worse geometry. From the same declaration T improved 1.1 dB at 10° N and worsened 1.3 dB at the equator, figures the depth pair finds firm. A tighter payload commitment is not monotone for compliance.

Tech · the capacity of 4 at depth

* The table is a 0.1 d run. The capacity of 4 has a convergence pair of its own: reruns at 0.5 d and 1.0 d that reuse its declaration, each read against the baseline at the same depth.

At 0, 10, 20 and 30° N, where no figure moved between the two depths, T reads −1.3, +1.1, +0.6 and −0.2 dB against the baseline: both directions, firm. At 40 and 50° N the cap-4 truth moved 2.8 and 2.9 dB between the depths, as the baseline’s did at the same two latitudes; the two systems move together there, and their matched-depth difference stays within 0.5 dB (0.0 and −0.5 at 0.5 d, 0.0 and −0.2 at 1.0 d). 60° N reads −0.6, then −0.2.

The 0.1 d figures did not all survive: the equatorial +1.5 read at 0.1 d is −1.3 at both depths. On the examination side the widest gap is 11.0 → 5.9 dB at 1.0 d, and E1 alone gains 3.6 to 6.4 dB by latitude at 0.5 and 1.0 d: the envelope gain of the 0.1 d row is depth-stable. The mechanism, reassignment moving the interference, stands either way.

The declared exclusion does not move the examination

On both mask shapes met so far, the MIN_EXCLUDE declaration has no effect on E1. The whole E1 gain of the capacity of 4 is the top-4 envelope’s, not the tightened exclusion’s. All three runs are at 0.1 d.

  • The capacity of 4 changed the R set too. The saturated probe could not place 47% of peak demand, and MIN_EXCLUDE tightened to 26.5° and 33.0° at the 35° and 45° bands, against 22.0° everywhere in the baseline. The examination reads that array, so the E1 gain could not at first be attributed to the envelope alone.
  • The control. An examination-only run held the baseline R set fixed and swapped in the cap-4 mask. It differs from the cap-4 run at one latitude by 0.1 dB and at the other six not at all. The exclusion’s share is nil, and the whole E1 gain, 3.5 to 6.4 dB by latitude, is the envelope’s.
  • No zone at all. With MIN_EXCLUDE forced to 0° against the baseline mask, E1 moved at none of the seven latitudes, and max epfd by +0.1 dB at one.

The reason is not a notch in the mask. In the derived mask, power within 3 dB of the peak reaches α 12–16° against the declared 22°: the main-lobe edge of beams gated at their boresight reaches the neighbouring ground at this cell size. The mechanism is the examination’s own:

  • its Step 22 counts main-beam satellites regardless of the zone;
  • when the zone is lifted, the same satellites, being the strongest, are the first the capped pick takes;
  • in-zone satellites near the victim’s boresight are summed either way, and the rest are too weak to register.

The filed two-level mask measures inert for the complementary reason: its in-zone values sit 30 dB down. So the consistency check reports each mask’s own reach into the declared zone rather than assuming one.

What is left of the gap

For a payload that declares nothing beyond its reuse plan, the declaration-side levers are spent on STEAM-2. What remains is the envelope’s price: the cost of describing a whole operating space with a single conservative surface.

  • The service span certifies nothing on a global system.
  • The mask grid is converged at 0.1 dB.
  • The beam count has no warrant until the payload declares its co-frequency beam capacity, a real property of the hardware. Declared at the probe’s own Ksat, it recovers 0.0 to 1.8 dB with T untouched (0.1 d).
  • What remains with the capacity declared at 20 is 6.4 to 10.9 dB in band (0 to 50° N, the declared service latitudes) at 0.1 d.
  • Without a declared capacity the gap reads 7.5 to 10.7 dB in band at 1.0 d (11.0 at 60° N), and 6.4 to 8.4 at 0 to 40° N at 16.0 d; the depth finding below has every depth.
  • A capacity below what today’s traffic reaches recovers more, but it moves T, in both directions, since refused links are reassigned rather than dropped. That makes it a design decision about the system rather than a better description of it.

Depth: the body settles, the tail keeps moving

The derivation does not move with depth; the truth does. The body of each distribution settles by 0.5 d, but the short-term end, where the verdict is decided, keeps moving, because each doubling of the run can find a rarer, stronger geometry. The gap moves less than either curve.

The same sweep of truth and examination at seven run lengths, each an extension of the last on one 60 s sample grid. The 0.1 d and 1.0 d runs derived their declarations; the other depths reuse the 0.1 d one.

  • The derivation. The R set derived at 1.0 d is identical to the 0.1 d one row for row, and its mask agrees at every one of 123 431 lit cells to 0.01 dB. E1’s movement with depth is the examination sampling a fixed declaration.
  • The truth moved by up to 5.4 dB at single latitudes between 0.1 and 1.0 d, flattening to −9.3 to −10.9 dB across all seven.

Doubling by doubling, T point margins:

  • 0.5 → 1.0 d: no figure moved by more than 0.5 dB at 0, 10, 20, 30 and 60° N; 40 and 50° N moved 2.8 and 2.6 dB.
  • 1.0 → 2.0 d (the run meant to pair those two): 40 and 50° N moved 0.1 and 0.6 dB. It also moved 10, 20 and 30° N, which the first pair had called firm, by 1.0, 2.7 and 1.2 dB; the maximum at 20° N rose 2.7 dB in the second day.
  • 2.0 → 4.0 d: the equator moved 1.1 dB and 50 and 60° N 0.7 each; the other four stayed where they were.
  • 4.0 → 8.0 d: 20° N alone moved, by 1.1 dB as its maximum rose again; no other latitude by more than 0.2.
  • 8.0 → 16.0 d: the equator moved 1.4 dB and 10° N 1.8 as their maxima rose; no other latitude by more than 0.3.

So from 0.5 d on, each doubling moves one to three latitudes by 1 to 3 dB and the others by 0.7 dB or less, and the set that moves changes from one doubling to the next. Two mechanisms drive it:

  • a maximum can only rise as the run is extended (20° N, +2.7 dB in the second day);
  • a resolved percentile can fall as rarer samples dilute a cluster (60° N: its maximum unchanged since 0.5 d, its worst margin improved by 1.0 dB over three doublings).

A convergence pair therefore firms the body of the distribution and only ever provisionally its tail.

Tech · the long runs under the limit-curve rule

The 8.0 d run, the first under the limit-curve rule, names each latitude’s deciding point: the maximum at 0 to 40° N, the 1% point at 50 and 60° N. It reports the curve crossing at −164.1 dB on the 0.029% segment at every latitude, and the curve margin binds only at 40° N, by 0.2 dB. At 16.0 d the deciding points and the crossing bin are the same, and the curve margin binds only at 50° N, by 0.5 dB. The tables quote the point margins. On the parallel build the 2.0 d sweep took 33 minutes, the 4.0 d one 75, the 8.0 d one 128 and the 16.0 d one 211. Differences at fixed depth stand; absolute short-term levels carry their run length, at any run length.

The time step

A 60 s step under-samples the maxima that decide the verdict. On STEAM-2 a 1 s step reads within 0.1 dB of the time step S.1503-4 prescribes, so the tool presets 1 s.

  • The fastest crossing of the earth station’s 3 dB beam by a STEAM-2 satellite takes 3.34 s. A 60 s step samples about one crossing in eighteen, so the maxima that decide the verdict at 0 to 40° N were starved of main-beam passes.
  • Over half a day, from 60 s to 6 s, the truth’s maximum rose 2.0 to 3.3 dB at 0 to 50° N and the gap closed by 0.5 to 2.9 dB at 0 to 40° N. E1 ≥ T still held at every latitude.
  • Over half a day the examination reads within 0.1 dB of the S.1503-4 step at 1 s and within 0.5 dB at 6 s. At 60 s the S.1503-4 step moves its point margin by −2.2 to +3.0 dB.
  • The long runs had largely paid the step down with depth. E1 at 60 s over 16 d sits within 0.4 dB of E1 on the S.1503-4 step over half a day, and over 2 d within 0.9 dB. The truth over 16 d sits within 0.8 dB of the truth at 6 s over half a day, except at 30° N (1.6 dB).
  • So the 16 d figures on this page stand to about a dB, and the half-day and one-day figures at 60 s do not.
  • With the Random selection and no hold, the step is also the reselection period. The 6 s truth drew its selection ten times as often as the 60 s one: the step changed the traffic model as well as the sampling.

The Compliance loop window presets the step to 1 s, about three samples per crossing, and warns when a step samples the fastest crossing fewer than three times. Its Examination step choice examines a declared mask on the S.1503-4 time step instead; the truth and the advisors stay on the preset step.

Tech · the S.1503-4 time step

The fine step of S.1503-4 §D4.2 is the pass time across the GSO earth station’s 3 dB beam where that crossing is fastest, over Nhit = 16: for STEAM-2 a 3.34 s pass across the 1.156° beam at 1 150 km, a fine step of 0.208 s. The coarse step of §D4.7.1 is 20 fine steps, 4.16 s. The dual time step follows §D5.1.4.1 Sub-steps 6.1 to 6.3, each sample counted Tstep/Tfine times (Step 24). Three samples per crossing is this tool’s own threshold, where the measured maxima settled; the simulation methodology asks for at least five (Rec. ITU-R S.1325 revision draft §2.7.2).

The victim’s geometry

On STEAM-2 the victim’s geometry is worth about 2 dB to the examination at the equator and 0.6 dB or less elsewhere, at 2.0 d. The gap moves less than either curve, so the envelope’s price is a property of the declaration, not of where the victim looks.

Every run above places the victim at one geometry: the earth station at longitude 0, the wanted GSO satellite 10° east of it. The examination under S.1503-4 searches for the worst-case geometry itself; this tool does not, and the decomposition, whose three curves share the victim, has no term for it. What the fixed victim leaves out was measured by moving the GSO satellite:

  • the same sweep of truth and examination, the baseline declaration reused, at 0.5 d on a 60 s step, 0 to 60° N;
  • eight GSO longitude offsets from 10° west to 60° east, which take the wanted satellite from overhead at the equator down to 22° of elevation, and at 60° N from 22° down to 6°;
  • fifty-six victims; E1 ≥ T at every one.

  • the 10°-east default is the worst offset for E1 at 30, 50 and 60° N, and within 1.1 dB of the worst at 10 and 20° N;
  • it is not the worst at the equator, where the satellite overhead reads 2.1 dB worse on E1 and 4.3 on T, nor at 40° N at this depth, where 10° west reads 2.5 and 5.1 worse.

Five offsets were then run on to 2.0 d beside the 2.0 d baseline: 10° west, 0, 5, 45 and 60° east.

  • The equator’s difference stood. Overhead against 10° east reads 4.1 dB worse on T and 2.1 on E1 (4.3 and 2.1 at 0.5 d): firm across a quadrupling of depth.
  • The 40° N difference did not. The baseline’s own maximum there rose 2.7 dB between the depths, as the depth tables record, and 10° west reads 0.2 dB better on T and 0.6 worse on E1 at 2.0 d.
  • The two far offsets, whose E1 sat 0.6 and 1.1 dB below the default at 10 and 20° N at 0.5 d, read better than the default at every latitude at 2.0 d, on T and on E1, except E1 at 40° N with the satellite 60° east, which is level with it (−18.8 dB).
  • The larger of the two positive point margins any truth run has shown, +1.3 dB at the equator with the satellite 5° east at 0.5 d, was a low maximum: at 2.0 d it reads −4.4. Its curve verdict was FAIL at both depths: at 0.5 d the distribution crosses the 0.029% segment at −165.4 dB by 1.6 times the allowed percentage. The other, +0.4 dB at 10° N with the satellite 30° east at 0.5 d, also fails the curve and was not run to 2.0 d.

So at 2.0 d, over six offsets, the victim’s geometry is worth about 2 dB to the examination at the equator and 0.6 dB or less elsewhere, against an envelope component of 7 to 11 dB. E1 ≥ T at all 98 victims of both depths. The figure is a lower bound: eight offsets and 10° of latitude are coarse where the examination’s own search is fine, and the ES longitude was not moved. These runs used a 60 s step; at the default geometry, E1 over 2 d sits within 0.9 dB of the S.1503-4 step.

The Compliance loop window’s ES lon / GSO offset fields move the victim, as do the eslon= and gso= arguments of the console loop mode.

The rules that follow

Each of these was bought with a measurement, and each is stated so it can be checked rather than believed.

  • Measurement, not assertion. Every value in a derived R set is measured on the probe, and a derived pfd mask is computed from the reachable envelope, every beam position the payload is permitted to take; neither is written by hand. A mask that asserts can assert what the scheduler does not enforce.
  • Saturate before measuring. Traffic may only thin what is lit, so a declaration measured under traffic is smaller than the commitment it stands for.
  • Unvisited is not unreachable. Nothing is declared absent because a finite probe happened not to visit it. A null needs a closed-form certificate from declared commitments.
  • The read-rule law. A declared array is safe if and only if its read-rule reconstruction bounds the measurement everywhere, not merely if its rows are correct at their own coordinates (drawn below). Header attribute and per-latitude array are mutually exclusive per quantity. The nearest-row read is total: the outermost row governs every latitude beyond the table, so a set of rows is complete everywhere. A set carrying both forms of a quantity is an invalid filing: reported, not read under an invented precedence. An out-of-span fallback in the examination’s resolver read the first derived sets as no floor and no cap at 50 and 60° N until it was removed.
  • Figures travel with their controls. A margin carries the depth it was resolved at, the time step it was sampled at and the grid it was worst over. A comparison names what was held fixed. An absolute figure is quotable only with a convergence pair: the same statistic at depth d and at least 2d, moving no more than a stated tolerance, 0.5 dB by default and 0.1 dB the bin floor, with both depths and the tolerance named where the figure is quoted. Differences at matched depth remain quotable as differences. The percentile floor guards a percentile’s existence; the pair guards a value’s stability, which is a property of the artefact: a two-level mask settles at once, a side-lobe-structured one needs samples.
  • The acceptance test tests the derivation, not the system. If E1 falls below T, the declaration failed to envelope the system. That is a granularity failure of the measurement, never a compliance failure of the system.
  • Every grid is one of three things, and is named as such when introduced. A declaration: its read-rule reconstruction must bound the measurement. A measurement: its extrema travel with the grid. A prescription: reproducing it exactly is the requirement, as it is for the examination’s own worst-case geometry search. Five defects of one family were found in one day: the service-span certificate, the pfd mask rows, MIN_EXCLUDE, the sweep’s own latitude grid, and the granularity walk’s latitude axis, which rewarded the mask-row defect as recovery. Asking this question at the moment each grid was introduced would have caught every one before it ran.
  • The verdict is the limit curve, and every report says so. A distribution passes only if every tabulated Article 22 point passes and it nowhere crosses the log-linear curve between the points (tolerance 0.05 dB, read towards lower epfd). A point margin does not bound a crossing, and the point-wise test alone is the lenient reading. Reports and exports quote the point margin and the curve margin and name the rule.
Tech · how far the code satisfies the law

The nearest-read case is implemented as stated in the certificate: a row goes dark only when no latitude in the band it governs can reach the service span. The mask sampler reads each band at its centre and both edges and takes the maximum, which is exact where the emission varies monotonically across the band and approximate where it does not.

The interpolated case is implemented conservatively: the deriver applies a per-row sliding minimum, which satisfies the hull condition without exploiting it. The declaration it produces is safe and under-claims the exclusion the operator could have declared. The difference is exactly zero on both cases checked, where MIN_EXCLUDE is flat (22.0° on STEAM-2); it matters only where the table varies. The rule above is the rule; this box records how far the code has caught up with it.
